# Shop Builder — Role v0.1

## Purpose

Help people create simple digital storefronts and identity hubs inside OpenSourceCity.

A Shop Builder helps turn:
- skills
- ideas
- products
- services

into visible participation in the city economy.

---

## What This Role Does

A Shop Builder helps someone:

1. Create a digital identity
2. Set up a simple storefront or profile
3. Connect methods of receiving value
4. Present what they offer clearly

This role helps people move from:
> learner → participant → earner

---

## What Counts as a “Shop”?

A shop does NOT need to be complicated.

A shop can be:
- A single product page
- A service offer
- A donation/support page
- A digital art profile
- A teaching page
- A link hub

---

- myweb3shop.crypto

---

## Core Principle

> “Start simple. Improve over time.”

Do not wait for perfection before participation.

---

## What a Shop Should Include

At minimum:

1. Name or identity
2. What is offered
3. How value is received
4. One clear action

Examples:
- “Buy”
- “Support”
- “Book”
- “Contact”
- “View”

---

## Tools

- Domains
- Wallet addresses
- Link pages
- Simple graphics
- GitHub pages
- IPFS (optional)

---

## Recommended Style

Keep shops:
- Clean
- Understandable
- Mobile-friendly
- Human

Avoid:
- Overdesign
- Confusion
- Too many options

---

## Suggested Workflow

1. Identify a skill or offer
2. Create a simple identity page
3. Add a way to receive value
4. Share the page
5. Improve based on use

---

## Compensation Path

Early:
- Build practice shops
- Recognition
- Small Random Rain rewards

Mid:
- Paid setup assistance
- Custom storefront creation

Later:
- Full digital business development
- Revenue sharing
- Marketplace leadership

---

## Day 1 Task

Help ONE person create:

- A simple identity page
OR
- A basic storefront concept

Include:
- Name
- Offer
- Wallet/payment method
- One clear action button or instruction

Publish it publicly if possible.

---

## Record Format (simple)

- Date
- Shop or page created
- Purpose
- Link or domain used

---

## Rule

> “A simple working shop is better than a perfect unfinished one.”
