# OpenSourceCity Map v0.1

## Overview

This map shows the basic structure and flow of OpenSourceCity.

Each “building” represents a function, not a physical place.

## Flow Summary

1. Traffic enters through Signal Domains  
2. Users learn through Onboarding  
3. Value movement is supported by Wallet Managers  
4. Users either learn more or begin earning  
5. Value is distributed through Random Rain  
6. System repeats

---

## Purpose

This map exists to:

- Make the system visible  
- Allow others to replicate it  
- Show how domains function as infrastructure
