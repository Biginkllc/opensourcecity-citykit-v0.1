# OpenSourceCity CityKit v0.1

A replicable system for building domain-based digital cities.

OpenSourceCity is not a single website.  
It is a repeatable structure that helps people create local or global “cities” using:

- Domains
- Education
- Wallet guidance
- Value movement
- Builder roles
- Random Rain activation

## Core Goal

Global Duplication.

The purpose of CityKit is to give anyone a simple framework to start a digital city that can teach, onboard, activate, and support others.
